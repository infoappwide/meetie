Cookies and Local Storage

The website and iPhone app are distinct.

On This PageThis WebsiteThe iPhone AppChanges

This Website

The static website code does not use cookies, localStorage, advertising pixels or analytics SDKs. It embeds no external fonts, videos or maps and shows no non-functional cookie-consent button. Navigation uses ordinary links. Provider technical logs are separate; this is not a claim that IP addresses are never processed. Live hosting behaviour will be checked after publication.

The iPhone App

Session information is kept in secure device storage; language preference uses local storage. Temporary drafts and caches support screens. These are not website cookies. Saving a selected profile photo uploads it to the server. Uninstalling the app does not delete the server account.

Changes

If optional tracking technologies are added, their purpose, provider, retention and any required choice mechanism must be addressed. Marketing consent is not assumed for this release.
